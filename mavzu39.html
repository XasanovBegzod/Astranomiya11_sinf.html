39-MAVZU (75-§). Geliosentrik uchastkadagi harakat

11-sinf Astronomiya | II Qism: Kosmonavtika elementlari (162-bet)

1. Geliosentrik bosqichning fizikasi va tezliklarni qo‘shish (75-§)

Kosmik apparat (KA) Yerning ta’sir sferasidan (R_ts ≈ 925 000 km) tashqariga chiqqach, Yer va mo‘ljallangan sayyoraning gravitatsion ta’siri Quyosh tortishish kuchiga nisbatan nihoyatda kichik bo‘lib qoladi. Shu sababli geliosentrik uchastkada KA faqat Quyosh tortishish maydonida Kepler qonunlari bo‘yicha harakatlanuvchi sun’iy sayyora sifatida qaraladi.

V⃗_gelio = V⃗_⊕ + v⃗_∞  |  V_⊕ ≈ 29.78 km/s  |  V_par,☉ = √2 · V_⊕ ≈ 42.12 km/s
1 / a = 2 / r₁ − V_gelio² / μ_☉  |  ψ₀ = 180° − 360° · (t_parvoz / T_pl)
  • Tashqi sayyoraga uchish: v⃗_∞ vektori Yer harakati V⃗_⊕ yo‘nalishida bo‘lgani uchun V_gelio = V_⊕ + v_∞ (masalan, Mars uchun V_gelio ≈ 29.78 + 2.94 = 32.72 km/s).
  • Ichki sayyoraga uchish: v⃗_∞ vektori V⃗_⊕ ga qarama-qarshi yo‘nalgani uchun V_gelio = V_⊕ − v_∞ (masalan, Venera uchun V_gelio ≈ 29.78 − 2.50 = 27.28 km/s).
  • Quyosh tizimidan chiqish: Agar V_gelio ≥ 42.12 km/s bo‘lsa, KA parabola yoki giperbola bo‘ylab Quyosh tizimini abadiy tark etadi («Voyajer-1/2», «Pioner-10/11»).

Gravitatsion manyovr (perturbation assist): Apparat ulkan sayyora (masalan, Yupiter yoki Venera) ta’sir sferasidan uchib o‘tayotganda sayyoraga nisbatan tezlik moduli o‘zgarmaydi, biroq harakat yo‘nalishi buriladi. Natijada Quyoshga nisbatan tezlik (V⃗_gelio = V⃗_pl + v⃗_∞) bir tomchi ham yoqilg‘i sarflamasdan keskin oshishi yoki kamayishi mumkin.

3. 75-§ bo‘yicha 4 ta darajali yechimli masala

1-Masala (Oson — Marsga start burchagi): T_Mars = 687 sutka, Gomon parvozi vaqti t = 259 sutka bo‘lsa, start paytidagi konfiguratsiya burchagini (ψ₀) toping.
Δφ = 360° × (259 / 687) ≈ 135.7° ⇒ ψ₀ = 180° − 135.7° = +44.3° (Mars Yerdan 44.3° oldinda).
2-Masala (O‘rta — Veneraga start burchagi): T_Ven = 224.7 sutka, parvoz vaqti t = 146 sutka bo‘lsa, Veneraning start paytidagi burchak holatini (ψ₀) aniqlang.
Δφ = 360° × (146 / 224.7) ≈ 233.9° ⇒ ψ₀ = 180° − 233.9° = −53.9° (Venera Yerdan 53.9° orqada).
3-Masala (Murakkab — Geliosentrik katta yarim o‘q): Yer harakati yo‘nalishida v_∞ = 5.0 km/s tezlik bilan chiqqan KA ning geliosentrik orbitasi katta yarim o‘qini (a) toping (V_⊕ = 29.8 km/s).
V_gelio = 29.8 + 5.0 = 34.8 km/s; 1/a = 2 − (34.8/29.8)² = 0.6363 ⇒ a ≈ 1.57 a.b.
4-Masala (Olimpiada — Mars ta’sir sferasiga kirish tezligi): r₂ = 1.524 a.b., a_o‘t = 1.262 a.b., V_Mars = 24.13 km/s, V_⊕ = 29.78 km/s. Afeliydagi tezlik V₂ va Marsga nisbiy kirish tezligi v_∞,2 ni hisoblang.
V₂ = 29.78 × √(2/1.524 − 1/1.262) ≈ 21.47 km/s; v_∞,2 = 24.13 − 21.47 = 2.66 km/s.
